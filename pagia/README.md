# Παγία Προκαταβολή

Διαχείριση παγίας προκαταβολής για Σ.Α.Ε.Κ.: παραστατικά, προμηθευτές, πρακτικά, διαβιβαστικό, Ημερολόγιο Κίνησης — 2η Σ.Α.Ε.Κ. Ηρακλείου.
FastAPI + SQLite, σε Docker (Synology Container Manager). Παίρνει αριθμό από το Ηλεκτρονικό Πρωτόκολλο.

## Εγκατάσταση σε Synology

1. Στο File Station δημιούργησε τον φάκελο `docker/pagia` και βάλε μέσα τα περιεχόμενα του repository.
2. Δημιούργησε κενό φάκελο `data` δίπλα στον `app`.
3. Αντίγραψε το `pagia.env.example` ως `pagia.env` και συμπλήρωσε τις τιμές (από τον υπολογιστή, όχι με το Text Editor του Synology — χαλάει τα ελληνικά).
4. Container Manager → Project → Create → διάλεξε τον φάκελο `docker/pagia` → Build.
5. Η εφαρμογή ανοίγει στη θύρα **5501**.
6. Ρυθμίσεις → ανέβασε τα 4 πρότυπα Word (πρακτικά και διαβιβαστικό) με το λογότυπο και τα στοιχεία της σχολής σου.

## Σύνδεση με το Πρωτόκολλο

Το `PROTO_API_KEY` του `pagia.env` πρέπει να είναι ίδιο με το `API_KEY` του `protokollo.env`.

## Προσαρμογή για άλλη σχολή

Το όνομα της σχολής ορίζεται στο `SCHOOL_NAME` του `pagia.env` και στις Ρυθμίσεις της εφαρμογής.

## Τι δεν περιέχει

Τον φάκελο `data/` (βάση, πρότυπα) και το `pagia.env` (κωδικοί). Κάθε σχολή έχει τα δικά της.
